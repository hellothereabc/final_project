\section{Source Code, Data, and Artefacts}
\label{app:repository}

All source code, configuration, and the scripts that generate every table and
figure in this paper are available at:

\begin{center}
\url{https://github.com/hellothereabc/final_project}
\end{center}

The repository contains the experiment code and the iOS application used for
the on-device measurements. It also contains a README with build and run
instructions, this paper in PDF form, and a short screencast of the application
running on a physical device. Section~\ref{sec:artefact} describes the
provenance of the reported numbers.
